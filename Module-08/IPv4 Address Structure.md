
# The IPv4 Address Structure

> An IPv4 address isn't just a random set of numbers—it follows a clear hierarchical structure designed to help routers direct network traffic efficiently.

---

# Core Structure:
   
   Network vs. Host

# Key Takeaway Terms

* **IPv4 Address**:

      A logical 32-bit identifier assigned to network interfaces.

* **Octet**:

      One of the four 8-bit sections of an IP address, separated by decimal points.

* **Subnet Mask:**

      Defines the boundary between the network and host portions of an IP address.

* **Network Address:**

      Represents the logical network as a whole (e.g., 192.168.5.0).

* **Host Address:**

      Uniquely identifies a specific endpoint on a given network (e.g., 192.168.5.11).
