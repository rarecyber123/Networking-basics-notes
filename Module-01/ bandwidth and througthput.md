
# ⚡ Bandwidth and Throughput

## 📌 Overview
Data transfer ki performance aur speed ko measure karne ke liye do primary concepts ka istemal kiya jata hai: **Bandwidth** aur **Throughput**. Dono data flow se related hain lekin inka matlab alag hai.

---

## 🏎️ Key Differences

### 1. Bandwidth (Maximum Capacity)
* **Definition:** Bandwidth is the maximum capacity of a network link to transfer data in a given amount of time.
* **Analogy:** **Highway ke lanes ki count.** Jitni zyada lanes hongi, utni zyada cars ek sath guzar sakti hain.
* **Nature:** Theoretical potential (Maximum possible speed).

### 2. Throughput (Actual Transfer Rate)
* **Definition:** Throughput is the actual measure of data transferred over the medium over a given period of time.
* **Analogy:** **Actual Traffic Speed.** Highway par kitni gaadiyaan sach mein smooth speed se travel kar pa rahi hain (traffic jam, construction, ya weather delay ke baad).
* **Nature:** Real-world performance (Always less than or equal to Bandwidth).

---

## 📊 Comparison Table

| Feature | Bandwidth | Throughput |
| :--- | :--- | :--- |
| **Concept** | Maximum potential capacity | Actual data transferred |
| **Measurement** | Bits per second (bps, Mbps, Gbps) | Bits per second (bps, Mbps, Gbps) |
| **Key Factor** | Hardware capability & media type | Network traffic, latency & congestion |
| **Real-world analogy** | Highway width (number of lanes) | Actual traffic flow speed |

---

## ⚠️ Factors Affecting Throughput

Throughput humesha Bandwidth se kam hota hai. Iske main reasons hain:
1. **Amount of Traffic:** Network par bohot saare devices ka ek sath active hona.
2. **Type of Data:** Multiple types of data traffic being transferred.
3. **Latency:** Data ko source se destination tak pahunchne mein lagne wala time delay.
4. **Network Devices:** Switches, routers, aur network media ki intermediate limitations.

> 💡 **Key Takeaway:** Bandwidth is what your network package promises (e.g., 100 Mbps), while Throughput is the actual speed you experience when downloading a file!
