
# Port Numbers

### Port Numbers Ka Kaam:

> Jab hum internet use karte hain (jaise web browsing, email, ya FTP), to transport layer par Port Numbers ke zariye alag-alag communications aur services ko pehchana jata hai. Har host jo message bhejta hai usme Source Port aur Destination Port dono shamil hote hain.

---

# ICANN Range aur Categories (1 se 65,535):

- Well-Known Ports (1 – 1023): Yeh common network services ke liye reservation hoti hai (jaise HTTP ke liye port 80).
  
- Registered Ports (1024 – 49151): Yeh specific applications ya companies ke liye hote hain (jaise instant messaging apps).

- Private / Dynamic Ports (49152 – 65535): Yeh ziada tar dynamic source ports ke taur par client side se automatically generate hote hain.

---

# Socket Pairs 

- ## Socket:

   IP Address aur Port Number ka combo hota hai (e.g., 192.168.1.5:1099).

- ###  Socket Pair:

   Client aur Server dono ke sockets mil kar ek socket pair banate hain (maslan: 192.168.1.5:1099, 192.168.1.7:80).

- ### Fayda:

   Is ki wajah se ek hi computer par ek saath multiple web pages ya services bager mix huay chal sakti hain.
