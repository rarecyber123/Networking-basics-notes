
# 1. Media Types (Signal Encoding)

Data network par transmit hone ke liye teen tarah ke media use karta hai:

- ### Metal Wires (Copper Cables):
  Data ko electrical impulses me convert/encode karta hai.

- ### Fiber-Optic Cables:
   Data ko light pulses (roshni) ke zariye bheja jata hai.

- ### Wireless Transmission:
  Data ko electromagnetic waves ke frequencies modulate karke transmit kiya jata hai.
