
# 1. Client aur Server ka Role

- ## Server:

   Ek powerful host machine/software jo data ya services provide karti hai (jaise Web, Email, ya File servers).

- ## Client:

  Application ya device jo server se request karti hai (jaise Chrome browser, Outlook, ya File Explorer). Ek hi computer ek saath multiple client apps chala sakta hai.

 - ## Key Factor:

    Server aur client ke aapas mei baat karne ke liye predefined standards aur protocols use hote hain.

   ---

# 2. Common Server Types

- ## Web Server:

   Web pages serve karta hai $\rightarrow$ Browser (Chrome/Firefox) se access hota hai.

  - ## Email Server:

     Mail handle karta hai $\rightarrow$ Email client (Outlook) se access hota hai.

    - ## File Server:

       Files central location par store karta hai $\rightarrow$ File Explorer se access hota hai.
