
# Web Client and Server

> Jab aap browser mai kisi website ki URL type karte hain, toh background mai web clients (aapka browser) aur web servers ke darmeyan conversation hoti hai.

---

# Web Requests Aur Protocols

- ## IP Address Aur Port 80 (HTTP):

   Jab browser ko DNS ke zariye server ka IP address mil jata hai, toh woh Port 80 ka istemal karke server ko HTTP request bhejta hai.

- ## HTML Content Response:

   Server request receive karne ke baad client ko HTML page bhejta hai. HTML code browser ko batata hai ke text, images aur layout ko screen par kaise display karna hai.

- ## Port 443 (HTTPS - Secure):

  Standard HTTP secure nahi hota (data intercept ho sakta hai). Iss wajah se security ke liye HTTPS ka istemal hota hai jo Port 443 par kaam karta hai aur data ko encrypt karta hai.
