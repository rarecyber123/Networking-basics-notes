
- # DNS (Domain Name System):

  Domain names (jaise google.com) ko machine-readable IP addresses mei convert/resolve karta hai.

- # SSH (Secure Shell):

   Remote servers ya networking devices ko securely access aur manage karne ke liye use hota hai.

  SMTP (Simple Mail Transfer Protocol): Emails aur attachments ko send karta hai (client to server ya server to server).

POP & IMAP: Email clients (jaise Outlook) ke zariye server se emails download/retrieve karne ke kaam aate hain.

DHCP (Dynamic Host Configuration Protocol): Devices ko automatically IP addresses aur networking details allocate karta hai taaki wo internet se connect ho sakein.
