
## HOST
> Hosts can send and receive messages on the network
> Host client ya server dono ki terh act kar sakta hai .
> Network se connected wo tamam computers jo direct communication m hissa lete hain.

---

## SERVER
> Wo host jo baki hosts ko info provide kare.

### Requirement: Har service ke liye alag server software chahiye hota hai (e.g., Web Server Software).

---

## CLIENT
>  Wo host jo server se milli hui info ko request aur display kar sake.
> Examples   : Web Browsers (Chrome, Firefox, Safari, Internet Explorer).

---

## Peer-to-Peer network (P2P)

> Jab ek hi computer client aur server dono ke software ek sath chala raha ho.

### Larger P2P  : **Multiple PCs ko connect karne ke liye switch jaisa network device chahiye hota hai.**

## P2P ADVANTAGES & DISADVANTAGES

|Advantages|Diadvantages|
|---|---|
|Easy to set up | Less complex | Lower cost | Simple tasks (file transfer, printer sharing) ke liye best.
| Disadvantages | No centralized administration | Not as secure | Not scalable | Performance slow honi ka risk.
