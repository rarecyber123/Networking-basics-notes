
# NETWORK INFRASTRUCTURE

### Platform    
> Wo foundation jo communication ke liye stable aur reliable channel provide karti hai.

 **Hardware Categories**
 
   - End Devices
   - Intermediary Devices
   - Network Media

---

# END DEVICES / HOSTS

### Role     

 User aur network ke darmiyan interface; message ka Source ya Destination hota hai.
 
### Address    

Uniquely identify karne ke liye IP/Network addresses use hote hain.


### Examples   :
   - Computers            : Workstations, laptops, file servers, web servers.
   - Printers             : Network printers.
   - Telecommunications   : IP phones, TelePresence endpoints, teleconferencing equipment.
   - Security             : Security cameras.
   - Mobile Devices       : Smartphones, wireless tablets, PDAs, wireless debit/credit card readers, barcode scanners.
